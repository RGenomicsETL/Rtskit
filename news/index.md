# Changelog

## Rtskit 0.0.0.9000

- Added native source-population ancestry-interval extraction with
  explicit unresolved-lineage handling.
- Added population and individual tables plus exact raw metadata and
  schema access.
- Expanded the deterministic example to exercise recombining ancestry
  sources.
- Added a pkgdown site and R-universe distribution metadata.
- Added an initial native, Python-free binding to the bundled tskit C
  API.
- Added tree-sequence loading, writing, summaries, node and edge access,
  sample IDs, tree intervals, and deterministic in-memory example data.
